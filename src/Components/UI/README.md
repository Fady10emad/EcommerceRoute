# Shared UI Components

This folder contains reusable presentation components to standardize the new design system.

Components:

- Button: Variants (primary, secondary, outline, ghost, danger) & sizes (sm, md, lg)
- Input: Form input with label & error state
- Card: Simple container with optional interactive hover
- Badge: Status labels (brand, accent, gray, danger)
- Loader / FullscreenLoader: Lightweight animated spinner components
- Modal: Accessible dialog with fade in animation
- SectionContainer: Section header pattern with title/subtitle/actions
- Skeleton / ProductCardSkeleton: Loading placeholders

All components rely purely on Tailwind utility classes; logic unchanged.
